# **App Name**: Zona Fit GT Online

## Core Features:

- Product Catalog: Display a catalog of products including name, price and availability.
- Product Filtering: Allow users to filter and sort products based on categories like gender, type and brand.
- Promotional Content: Display banners and carousels on the homepage to showcase new arrivals or special promotions.
- Predictive Search: Provide a search bar allowing users to search products, filter, sort and see product names.

## Style Guidelines:

- Primary color: Deep purple (#4B0082) to convey sophistication and strength.
- Background color: Light gray (#F0F0F0) for a clean, modern backdrop.
- Accent color: Bright Cyan (#00FFFF) to highlight interactive elements.
- Body font: 'Inter', sans-serif, for a clean and modern look. Headline Font: 'Space Grotesk', sans-serif, for a techy feel.
- Use a set of modern, minimalist icons to represent different categories.
- Ensure a responsive layout that adapts seamlessly to different screen sizes.
- Implement subtle animations on button hovers and page transitions for added interactivity.
